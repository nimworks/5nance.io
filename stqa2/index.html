Practical No. 4: Selenium Server (Grid) Configuration and Remote Execution

Aim

To install and configure Selenium Server (Grid) and execute the same test script on multiple browsers (Chrome and Firefox) using Remote WebDriver.

Theory

  • Selenium Grid: A tool within the Selenium suite that allows automation scripts to run on different browsers, operating systems, and machines simultaneously. It uses a Hub-Node architecture (or a unified standalone mode) to achieve distributed cross-browser testing.
  • Remote WebDriver: An implementation class used to connect the local automation test script to a remote browser runner environment hosted on a Selenium Grid server, rather than launching local driver binaries directly on the host machine.
  • Cross-Browser Testing: A verification technique performed to check whether a web application behaves consistently and renders correctly across various web browsers such as Google Chrome and Mozilla Firefox.

Tools Required

  • Selenium Server (Grid) Standalone JAR File (selenium-server-4.44.0.jar)
  • Eclipse IDE / IntelliJ IDEA
  • Java JDK (Version 8 or above)
  • Google Chrome Browser & ChromeDriver
  • Mozilla Firefox Browser & GeckoDriver

Procedure

Step 1: Download the Selenium Server JAR

Download the latest or required Selenium Server standalone executable package file (selenium-server-4.44.0.jar) and place it in a dedicated working folder.

Step 2: Start Selenium Grid Server

  1. Open the Command Prompt (Windows) or Terminal (macOS/Linux).
  2. Navigate to the directory containing the downloaded JAR file using the cd command.
  3. Start the Selenium Grid in standalone mode by running: 
    java -jar selenium-server-4.44.0.jar standalone
  4. Wait for the terminal initialization log stream messages to confirm that the server is successfully running and listening on port 4444 (http://localhost:4444).

Step 3: Setup Project in Eclipse IDE

  1. Launch Eclipse IDE.
  2. Create a new Java Project: Go to File → New → Java Project and name it SeleniumGridDemo.
  3. Create a new source package package framework named grid.
  4. Create a new Java class within the package and name it GridTest.java.
  5. Add the downloaded selenium-server-4.44.0.jar to the project’s Build Path:
    • Right-click on the project → Build Path → Configure Build Path.
    • Click the Libraries tab → select Classpath → click Add External JARs…
    • Select your downloaded Selenium Server JAR file and click Apply and Close.

Step 4: Automation Script Implementation

Write the following code inside the GridTest.java file:

package grid;

import java.net.URL;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeOptions;
import org.openqa.selenium.firefox.FirefoxOptions;
import org.openqa.selenium.remote.RemoteWebDriver;

public class GridTest {
    public static void main(String[] args) {
        try {
            // Configure Chrome Options
            ChromeOptions chromeOptions = new ChromeOptions();

            // Initialize Remote WebDriver for Google Chrome
            WebDriver driver1 = new RemoteWebDriver(
                new URL("http://localhost:4444"),
                chromeOptions
            );

            // Execute test actions on Chrome
            driver1.get("https://google.com");
            System.out.println("Chrome Title: " + driver1.getTitle());
            driver1.quit();

            // Configure Firefox Options
            FirefoxOptions firefoxOptions = new FirefoxOptions();

            // Initialize Remote WebDriver for Mozilla Firefox
            WebDriver driver2 = new RemoteWebDriver(
                new URL("http://localhost:4444"),
                firefoxOptions
            );

            // Execute test actions on Firefox
            driver2.get("https://google.com");
            System.out.println("Firefox Title: " + driver2.getTitle());
            driver2.quit();

        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

Step 5: Run the Code

  1. Save the program using Ctrl + S.
  2. Right-click on GridTest.java in the project explorer tree pane.
  3. Select Run As → Java Application.

Console Execution Output

Expected Result

The Selenium Server (Grid) engine initializes successfully on the loopback port 4444. The compiled Java test automation program connects via RemoteWebDriver to distribute script commands, causing both Chrome and Firefox browsers to launch and pull down web content concurrently as expected.

package login;

import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.chrome.ChromeDriver;

public class LoginAuto {
    public static void main(String[] args) {
        // Create WebDriver object
        WebDriver driver = new ChromeDriver();

        // Open website
        driver.get("https://practicetestautomation.com");

        // Maximize browser
        driver.manage().window().maximize();

        // Enter username
        driver.findElement(By.id("username")).sendKeys("student");

        // Enter password
        driver.findElement(By.id("password")).sendKeys("Password123");

        // Click Login button
        driver.findElement(By.id("submit")).click();

        // 1. URL Validation
        String expectedURL = "https://practicetestautomation.com";
        String actualURL = driver.getCurrentUrl();
        if (actualURL.equals(expectedURL)) {
            System.out.println("URL Validation Passed");
        } else {
            System.out.println("URL Validation Failed");
        }

        // 2. Welcome Message Validation
        WebElement message = driver.findElement(By.tagName("h1"));
        if (message.getText().equals("Logged In Successfully")) {
            System.out.println("Welcome Message Validation Passed");
        } else {
            System.out.println("Welcome Message Validation Failed");
        }

        // 3. Logout Button Validation
        WebElement logout = driver.findElement(By.linkText("Log out"));
        if (logout.isDisplayed()) {
            System.out.println("Logout Button is Visible");
        } else {
            System.out.println("Logout Button is Not Visible");
        }

        // Close browser
        driver.quit();
    }
}

Practical No. 6: Web Element Interaction and Synchronization Handling

Aim

To automate interaction with various web elements such as textbox, password field, textarea, dropdown, checkbox, radio button, alert, and frame using Selenium WebDriver (Java) and implement implicit and explicit waits for synchronization handling.

Theory

  • Web Element Interaction: Selenium provides various methods to interact with standard HTML elements. Common methods include sendKeys() for text inputs, click() for buttons, checkboxes, and radio buttons, and the Select class for handling dropdown menus.
  • Synchronization Handling: Web applications often use asynchronous JavaScript or AJAX to load content dynamically. To prevent tests from failing due to timing issues, synchronization is handled using:
    • Implicit Wait: Tells the WebDriver to poll the DOM for a certain duration (e.g., 10 seconds) when trying to find any element before throwing a NoSuchElementException.
    • Explicit Wait: Configured using the WebDriverWait and ExpectedConditions classes to pause execution until a specific conditional criteria (e.g., visibility, element clickability) is fulfilled for a specific target locator.

Software Requirements

  • Eclipse IDE / IntelliJ IDEA
  • Java JDK 18 or above
  • Google Chrome Browser & compatible ChromeDriver
  • Selenium Server JAR (selenium-server-4.44.0.jar)

Websites Used

  1. Web Form: https://selenium.dev
  2. Alert Demo: https://herokuapp.com
  3. Frame Demo: https://herokuapp.com

Procedure

  1. Open Eclipse IDE and create a new Java Project named WebElementAutomation.
  2. Add the Selenium Server JAR to your project configuration Build Path under Libraries.
  3. Create a package named webelement and a class named ElementInteraction containing a standard main method execution loop.
  4. Import the required Selenium library classes (Alert, Select, WebDriverWait, etc.).
  5. Write the automation program to handle form submission, pop-up JavaScript alert handling, and frame switching sequences sequentially.

Code Implementation

package webelement;

import java.time.Duration;
import org.openqa.selenium.Alert;
import org.openqa.selenium.By;
import org.openqa.selenium.Keys;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.support.ui.ExpectedConditions;
import org.openqa.selenium.support.ui.Select;
import org.openqa.selenium.support.ui.WebDriverWait;

public class ElementInteraction {
    public static void main(String[] args) {
        // Launch Chrome Browser
        WebDriver driver = new ChromeDriver();

        // Configure Implicit Wait
        driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));

        // Maximize Browser
        driver.manage().window().maximize();

        // Configure Explicit Wait instance
        WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));

        // --- PART 1: Web Form Elements Interaction ---
        driver.get("https://selenium.dev");

        // Textbox
        driver.findElement(By.name("my-text")).sendKeys("Kiran Sahani");
        System.out.println("Textbox entered successfully");

        // Password
        driver.findElement(By.name("my-password")).sendKeys("12345");
        System.out.println("Password entered successfully");

        // Text Area
        driver.findElement(By.name("my-textarea")).sendKeys("Selenium Practical");
        System.out.println("Textarea entered successfully");

        // Dropdown Selection
        Select dropdown = new Select(driver.findElement(By.name("my-select")));
        dropdown.selectByVisibleText("Two");
        System.out.println("Dropdown selected successfully");

        // Checkbox
        driver.findElement(By.id("my-check-1")).click();
        System.out.println("Checkbox selected successfully");

        // Radio Button
        driver.findElement(By.id("my-radio-2")).click();
        System.out.println("Radio button selected successfully");

        // Submit Button Click
        driver.findElement(By.cssSelector("button")).click();
        System.out.println("Form submitted successfully");

        // --- PART 2: JavaScript Alert Handling ---
        driver.get("https://herokuapp.com");

        // Explicit wait applied to ensure clickability of alert button
        wait.until(ExpectedConditions.elementToBeClickable(
            By.xpath("//button[text()='Click for JS Alert']"))).click();

        // Switch to the Alert modal context overlay
        Alert alert = driver.switchTo().alert();
        alert.accept(); // Confirms and dismisses the alert pop-up
        System.out.println("Alert handled successfully");

        // --- PART 3: iFrame Handling ---
        driver.get("https://herokuapp.com");

        // Explicit wait to check frame availability and auto-switch into its context window
        wait.until(ExpectedConditions.frameToBeAvailableAndSwitchToIt(By.id("mce_0_ifr")));

        // Interact with elements located inside the swapped iframe window context
        WebElement frameText = wait.until(
            ExpectedConditions.visibilityOfElementLocated(By.id("tinymce")));

        frameText.sendKeys(Keys.CONTROL + "a");
        frameText.sendKeys(Keys.DELETE);
        frameText.sendKeys("Frame handled successfully.");

        // Switch back out to the parent main document page level context mapping
        driver.switchTo().defaultContent();
        System.out.println("Frame handled successfully");
        System.out.println("Practical executed successfully");

        // Close Browser Session
        driver.quit();
    }
}

Console Execution Output

Expected Result

The script runs sequentially, seamlessly switching browser contexts between regular components, active JavaScript alert dialog models, and deep nested text iframes with synchronization intervals fully handled by the implicit and explicit configurations.

            for (int i = 0; i < students.length; i++) {

                Row row = sheet.getRow(i + 1);

                row.createCell(0).setCellValue(students[i][0]);
                row.createCell(1).setCellValue(students[i][1]);
                row.createCell(2).setCellValue(students[i][2]);
                row.createCell(3).setCellValue(students[i][3]);
                row.createCell(4).setCellValue(students[i][4]);
            }

            // Close the input file parsing layer stream safely
            fis.close();

            // Open an output communication stream to rewrite data states to the physical disk file
            FileOutputStream fos = new FileOutputStream(filePath);
            workbook.write(fos);

            // Flushes data allocations and releases underlying document lock structures
            fos.close();
            workbook.close();

import java.time.Duration;
import java.util.List;
import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.chrome.ChromeDriver;

public class CheckboxIdentification {
    public static void main(String[] args) throws InterruptedException {
        // Launch Chrome browser instance
        WebDriver driver = new ChromeDriver();

        // Maximize browser container layout boundaries
        driver.manage().window().maximize();

        // Configure Implicit synchronization timeout interval
        driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));

        // Open the targeted playground checkbox demo web page
        driver.get("https://lambdatest.com");

        // Locate all checkboxes on the page using a type attribute locator path
        List<WebElement> checkboxes = driver.findElements(By.xpath("//input[@type='checkbox']"));

        // Extract aggregate checkbox collection inventory sizes
        int totalCheckboxes = checkboxes.size();
        System.out.println("==================================");
        System.out.println("     CHECKBOX IDENTIFICATION      ");
        System.out.println("==================================");
        System.out.println("Total Number of Checkboxes: " + totalCheckboxes);

        // Loop through and click the first 5 unchecked checkboxes found
        for (int i = 0; i < 5 && i < checkboxes.size(); i++) {
            if (!checkboxes.get(i).isSelected()) {
                checkboxes.get(i).click();
            }
        }

        // Count checked vs unchecked states within the element list matrix
        int checkedCount = 0;
        int uncheckedCount = 0;
        for (WebElement checkbox : checkboxes) {
            if (checkbox.isSelected()) {
                checkedCount++;
            } else {
                uncheckedCount++;
            }
        }

        // Display initial selection count states
        System.out.println("Checked Checkboxes: " + checkedCount);
        System.out.println("Unchecked Checkboxes: " + uncheckedCount);

        // Perform a dynamic runtime selection test against an unchecked target
        for (WebElement checkbox : checkboxes) {
            if (!checkbox.isSelected()) {
                checkbox.click();
                System.out.println();
                System.out.println("An unchecked checkbox was selected.");

                // Assert validation status state change parameters immediately
                if (checkbox.isSelected()) {
                    System.out.println("Validation Successful: Checkbox is selected.");
                } else {
                    System.out.println("Validation Failed: Checkbox is not selected.");
                }
                break; // Break the cycle loops cleanly after finding one item
            }
        }

        // Recalculate totals across the matrix to verify adjustments worked
        checkedCount = 0;
        uncheckedCount = 0;
        for (WebElement checkbox : checkboxes) {
            if (checkbox.isSelected()) {
                checkedCount++;
            } else {
                uncheckedCount++;
            }
        }
        System.out.println();
        System.out.println("After Dynamic Selection:");
        System.out.println("Checked Checkboxes: " + checkedCount);
        System.out.println("Unchecked Checkboxes: " + uncheckedCount);

        // Keep browser open for execution review observation

            afterSorting.add(name.getText());

Theory

In Selenium automation testing, sometimes a test case fails because an element cannot be found, a page does not load, or some other unexpected error occurs. A screenshot helps us see the exact state of the browser at the time of failure. This makes it easier to understand and debug the problem.

            logger.error("Error message: " + e.getMessage());

            // Capture screenshot
            if (driver != null) {
                try {
                    TakesScreenshot screenshot = (TakesScreenshot) driver;
                    File source = screenshot.getScreenshotAs(OutputType.FILE);
                    String timeStamp = new SimpleDateFormat("yyyyMMdd_HHmmss").format(new Date());
                    File destination = new File("screenshots/failure_" + timeStamp + ".png");

                    java.nio.file.Files.copy(
                        source.toPath(),
                        destination.toPath(),
                        java.nio.file.StandardCopyOption.REPLACE_EXISTING
                    );
                    logger.info("Screenshot captured: " + destination.getAbsolutePath());
                } catch (Exception screenshotError) {
                    logger.error("Unable to capture screenshot: " + screenshotError.getMessage());
                }
            }
        } finally {
            if (driver != null) {
                driver.quit();
                logger.info("Browser closed.");
            }
            logger.info("Test execution completed.");
        }
    }
}

Practical No. 14: Automation testing framework using Page Object Model (POM)

Aim

To design and implement an automation testing framework using Page Object Model (POM) with Selenium WebDriver and TestNG, by creating reusable page classes and executing modular test cases.

Tools Required

  • Java JDK
  • Eclipse IDE
  • Maven
  • Selenium WebDriver
  • TestNG
  • Google Chrome
  • ChromeDriver

Theory

Page Object Model (POM) is a design pattern used in Selenium automation testing. In POM, each web page is represented by a separate Java class. The page class contains the web elements and methods/actions performed on that page, while the test class contains the test cases and assertions.

This makes the automation framework:

  • Easy to understand
  • Reusable
  • Easy to maintain
  • Modular
  • Less repetitive

For example, instead of writing Google-related code directly inside the test class, we can create a GooglePage class and put the page-related actions there.

Procedure

  1. Create Maven Project: Create a Maven Project in Eclipse. Use Group Id: com.testing and Artifact Id: POMTesting. The project will automatically contain a pom.xml file.
  2. Configure pom.xml: Add Selenium and TestNG dependencies to the pom.xml.
  3. Create Page Class: Inside src/test/java → com.testing (package), create a Java class named GooglePage.java.
  4. Create Test Class: Now create SeleniumTest.java in the same package.
  5. Create testng.xml: Create testng.xml in the project root directory to manage execution.

Practical No. 15: TestNG Framework Implementation and Reporting

Aim

To create and execute automated test cases using TestNG annotations, group test cases, define test execution priorities, and generate an HTML test report using Selenium WebDriver and TestNG.

Tools Required

  • Java JDK 11 or above
  • Eclipse IDE
  • Maven
  • Selenium WebDriver
  • TestNG
  • WebDriverManager
  • Google Chrome
  • Internet connection

Theory

TestNG is a testing framework for Java that is used to create, organize, execute, and report automated test cases. TestNG provides annotations that control the execution of test methods. Some commonly used annotations are:

  • @BeforeMethod – executes before each test method.
  • @Test – identifies a method as a test case.
  • @AfterMethod – executes after each test method.

TestNG also supports priorities and groups. Priority is used to define the order of test execution, while groups are used to categorize related test cases. TestNG can also generate an HTML report after test execution. The report shows the number of tests executed, passed, failed, and skipped.

Procedure

  1. Create a Maven Project: Open Eclipse IDE → File → New → Maven Project. Select “Create a simple project” and enter Group Id: com.testing and Artifact Id: TestNGFramework.
  2. Create the Package: Inside src/test/java, right-click and create a package named com.testing.
  3. Create the Java Class: Inside the package, create a class named TestNGFrameworkTest.
  4. Configure pom.xml: Open the project’s pom.xml file and add dependencies for Selenium, TestNG, and WebDriverManager.
  5. Update Maven Project: Right-click the project → Maven → Update Project to download dependencies.
  6. Write the Java Program: Paste the complete TestNG code into your class file.
  7. Create testng.xml: Create the XML execution suite in the project root folder.

2. Test Class (TestNGFrameworkTest.java)

package com.testing;

import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.testng.Assert;
import org.testng.annotations.AfterMethod;
import org.testng.annotations.BeforeMethod;
import org.testng.annotations.Test;
import io.github.bonigarcia.wdm.WebDriverManager;

public class TestNGFrameworkTest {
    WebDriver driver;

    // Runs before every test case
    @BeforeMethod
    public void setUp() {
        WebDriverManager.chromedriver().setup();
        driver = new ChromeDriver();
        driver.manage().window().maximize();
        driver.get("https://google.com");
        System.out.println("Browser opened successfully");
    }

    // Test Case 1
    @Test(priority = 1, groups = {"smoke"})
    public void verifyTitle() {
        String title = driver.getTitle();
        System.out.println("Page Title: " + title);
        Assert.assertTrue(title.contains("Google"));
        System.out.println("Title test passed");
    }

    // Test Case 2
    @Test(priority = 2, groups = {"smoke"})
    public void verifyURL() {
        String url = driver.getCurrentUrl();
        System.out.println("Current URL: " + url);
        Assert.assertTrue(url.contains("google.com"));
        System.out.println("URL test passed");
    }

    // Test Case 3
    @Test(priority = 3, groups = {"regression"})
    public void verifyPage() {
        String title = driver.getTitle();
        System.out.println("Checking page title...");
        Assert.assertNotNull(title);
        System.out.println("Page verification test passed");
    }

    // Runs after every test case
    @AfterMethod
    public void tearDown() {
        if (driver != null) {
            driver.quit();
            System.out.println("Browser closed");
        }
    }
}
